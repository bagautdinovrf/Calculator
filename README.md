# Calculator

Класс `Calculator` вычисляет арифметические выражения через обратную польскую
запись. Публичный метод: `double calc(const char* str)`. Некорректный ввод,
деление на ноль, переполнение и результат вне области действительных чисел
вызывают `std::runtime_error`.

Поддерживаются десятичные числа с точкой (`.10`, `1.`, `1.25`), скобки,
операторы `+`, `-`, `*`, `/`, `^` и пробельные символы. Экспоненциальная
запись чисел и неявное умножение не поддерживаются.

Возведение в степень правоассоциативно: `2^3^2 = 512`, а `(2^3)^2 = 64`.
Сохранён исходный приоритет унарного минуса выше степени: `-2^2 = 4`;
для отрицания результата степени используйте `-(2^2) = -4`.
Можно использовать несколько унарных минусов и исходное обозначение `~`.

Сборка и тесты (CMake и компилятор C++17):

```sh
cmake -S src -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Исполняемый файл `Calculator` запускает пример из `src/main.cpp`.
Регрессионные тесты проверяют порядок операций, вложенные скобки, степени,
унарные минусы, числа, некорректный ввод и повторные вызовы после ошибки.

Алгоритм сортировочной станции — способ разбора математических выражений, представленных в инфиксной нотации. Может быть использован для получения вывода в виде обратной польской нотации или в виде абстрактного синтаксического дерева. Алгоритм предложен Эдсгером Дейкстрой и назван им «алгоритм сортировочной станции», поскольку напоминает действие железнодорожной сортировочной станции.

Так же, как и вычисление значений выражений в обратной польской записи, алгоритм работает при помощи стека. Инфиксная запись математических выражений чаще всего используется людьми, её примеры: 2+4 и 3+6*(3-2). Для преобразования в обратную польскую нотацию используется 2 строки: входная и выходная, и стек для хранения операторов, еще не добавленных в выходную очередь. При преобразовании алгоритм считывает 1 символ и производит действия, зависящие от данного символа.
